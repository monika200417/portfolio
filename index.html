MindTune

Real-Time Brainwave Detection and Music Therapy System using IoT.

MindTune is an IoT-enabled emotional wellness system that uses EEG brainwave signals to detect user emotions in real time. The system processes EEG data using FFT analysis on an ESP32 microcontroller and automatically provides personalized music therapy based on the detected emotional state. Designed as an affordable mental health support solution, it combines neuroscience, embedded systems, and IoT technologies for continuous emotional monitoring and therapeutic intervention.

Key features

  • Real-time EEG signal acquisition
  • Brainwave-based emotional detection
  • FFT signal processing
  • Automatic music therapy recommendation
  • Wi-Fi enabled IoT communication
  • Continuous emotional monitoring
  • Affordable health solution

Tech stack

  • ESP32
  • BioAmp EXG Pill
  • Embedded C
  • Arduino IDE
  • EEG Signal Processing
  • FFT Analysis
